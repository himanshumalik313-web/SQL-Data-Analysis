# SQL Data Analysis Project

## Overview
This project analyzes an e-commerce dataset using MySQL.

## Tools Used
- MySQL Workbench
- SQL
- CSV Dataset

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- COUNT()
- SUM()
- AVG()
- MAX()
- MIN()
- LIMIT
- Window Functions

## Analysis Performed

- Total number of orders
- Top-selling products
- Revenue by payment method
- Average order value
- Cancelled vs Returned orders
- Top referral sources
- Customer order analysis

## Dataset
- Total Records: 1200
- Columns: 14

## Conclusion
The analysis identified the best-selling products, customer purchasing patterns, payment trends, and order status distribution.
